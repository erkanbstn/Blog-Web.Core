# Blog

Yazı, kategori ve grafiklerle yönetilen blog sitesi.

## Ne var

Yönetim, blog ve kategori controller'ları vardır.

## Çalıştırma

Çözümdeki web veya API projesinde şu komutu çalıştırın:

```powershell
dotnet run
```

Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET 5, ASP.NET Core MVC, Entity Framework Core, Identity ve FluentValidation.
